# Learning v2

## 設計

学習エンジンがミッション・順序・進行を所有します。Tutorは状況に合ったプロンプトを提示し、Evaluatorは現在の学習者回答の意図と表現だけを評価します。LLMが年齢やXP、次のミッションを自由に変更する構成にはしません。

Baby LifeとReal Lifeは、同じ技能・成功条件を持つ別の場面です。最後のターンは場面を変えて、選択肢を外して使います。ヒント閲覧は永続化し、リロードしても「自力」に戻りません。18技能を順に3つずつの6章で進めます。プレイスメントは読み取り5問による開始地点の目安で、既存の技能を習得済みと記録しません。

## 永続化と復旧

Zustandのドメイン状態をZodで検証してからAsyncStorageに順序付きで書き込みます。読めない既存データは上書きせず、バックアップ復元を案内します。保存失敗時はメモリ上の学習を保持し、再保存／書き出しを案内します。クラウド同期はしません。履歴の保持上限は1000セッションです。

結果画面のXPは、同一ミッション全体で最大60。初回の練習完了10、後日自力でクリアしたときの残り50など、上限との差分だけを付与します。技能の年齢にはXPを使いません。復習予定は1日から最長30日で、失敗は10分後。復習の自己評価で年齢は上がりません。

## 評価範囲

例文モードは正規化した表現の完全一致と明示的な別表現だけを受け付けます。言い換えを広く判定できるとは表示しません。AIモードは認証・日次予算・構造化出力・Zod検証を通します。採点不能、拒否、不完全出力、タイムアウトは不正解として記録せず、入力を残して再試行します。

音声入力は文字に変換して確認後に送信します。ブラウザはWeb Speech、ネイティブは最大20秒の録音→Supabase→OpenAI文字起こしです。話し手の声や音韻情報を評価していないため、発音点数は表示しません。
